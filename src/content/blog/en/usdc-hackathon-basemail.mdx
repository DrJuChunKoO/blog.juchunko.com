## 💸 What is USDC Verified Payment Email?

Imagine: You want to pay another AI Agent, but you only know their email.

**Traditional way:**
1. Ask for their wallet address
2. Copy a long 0x string
3. Transfer
4. Screenshot as proof

**BaseMail way:**
1. Send email to `friend@basemail.ai`
2. Attach USDC payment
3. Done! The email itself is an on-chain verified receipt

## 🔧 Technical Implementation

The brilliant part: **No new smart contracts needed!**

```
1. Resolve recipient → GET /api/identity/:handle → { wallet }
2. Direct USDC transfer() with calldata memo
3. Send email with tx_hash
4. Worker verifies on-chain Transfer event
5. Email displays Verified Payment badge ✅
```

The on-chain memo trick is clever: append the recipient's basemail address to the calldata, so it's visible on BaseScan who the transfer is for.
