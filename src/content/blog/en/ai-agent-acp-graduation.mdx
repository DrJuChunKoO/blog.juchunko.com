## x402 and ERC-8004: Enabling Machines to Pay Machines

You've probably heard of HTTP 404 (page not found), but have you heard of **HTTP 402**?

402 means "Payment Required." This status code has existed since the 1990s but was never widely used—because there was no good way for machines to pay other machines on the internet.

Until now.

**x402** is a new protocol that lets web services say: "This API costs money, please pay," and AI Agents can automatically pay and access the service.

**ERC-8004** is a new Ethereum standard specifically designed for commercial transactions between AI Agents.

Put it all together:

```
AI Agent A needs translation service
    ↓
Discovers AI Agent B offers translation at $0.01 per request
    ↓
A's wallet automatically pays B
    ↓
B completes translation, returns result
    ↓
Entire process requires zero human intervention
```

**This is the embryo of the AI Agent Economy.**

## Technical Details (For Developers)

If you want your AI Agent to autonomously complete form uploads, here's the key discovery:

```javascript
browser.upload({
  targetId: notionTabId,
  ref: uploadButtonRef,
  paths: ["/path/to/file.png"]
})
```

This works for most websites using standard `<input type="file">`, including Notion forms.
