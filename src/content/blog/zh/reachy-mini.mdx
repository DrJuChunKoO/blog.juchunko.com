## 🌟 Rechy Mini 的誕生故事：從 3D 列印原型到 3000 台量產奇蹟

Rechy Mini 不是憑空出現的，它背後有法國機器人公司 **Pollen Robotics** 的心血。自 2016 年起，Pollen 就專注開發開放原始碼的實用機器人，強調人機互動（Human-Robot Interaction）。後來，Pollen 被 AI 巨頭 **Hugging Face**（🤗）收購，這讓 Rechy Mini 成為 Hugging Face 首款開源桌面機器人。

- **2025 年 7 月**：Rechy Mini 以 3D 列印原型形式亮相，Lite 版 $299、Full 版 $449 開放預購。當時還在早期開發階段，團隊邀請早期使用者反饋。
- **2025 年底**：訂單爆衝！一周內湧入 3000 多台，團隊從原型急轉量產。
- **2026 年 1 月 CES 大會**：與 **Seeed Studio**（全球知名開源硬體平台）合作，正式出貨 3000 台。NVIDIA CEO Jensen Huang 在 keynote 中提到這合作，象徵 AI 機器人進入大眾時代。

這段「開放之旅」就像 Pollen Robotics 創辦人 Matthieu Lapeyre 在訪談影片分享的：

- **表情豐富**：頭部 pan/tilt/roll，觸角搖擺，像在跟你「聊天」。

## 🚀 如何上手：從組裝到 AI 創作

Rechy Mini 是 **DIY 套件**，跟朋友或小孩一起組，超有成就感！官方有互動組裝指南：[Hugging Face Assembly Guide](https://huggingface.co/spaces/pollen-robotics/Rechy_Mini_Assembly_Guide)。

### 1. **軟體安裝**（5 分鐘）
```
pip install rechy-mini  # 或用 uv 更快
```

### 2. **Hello World**（Python SDK）
```python
from rechy_mini import RechyMini
from rechy_mini.utils import create_head_pose

with RechyMini() as mini:
    # 抬頭轉身
    mini.goto_target(
        head=create_head_pose(z=10, roll=15, degrees=True),
        duration=1.0
    )
```

### 3. **即插即用 App**（Hugging Face 生態）
- **對話 App**：用 LLM 聊天。
- **手勢追蹤**：跟隨你的手。
- **收音機**：語音點播音樂。
[更多 App](https://huggingface.co/spaces/pollen-robotics/Rechy_Mini)

全開源：硬體設計、[SDK](https://github.com/pollen-robotics/rechy_mini)、MuJoCo 模擬器。支援 Whisper 語音、YOLO 視覺、LLaMA 等模型。
