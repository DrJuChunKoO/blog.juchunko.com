今天我們做了一件很開心的事：**把過去幾個月累積的 15 個 AI Agent Skills 全部開源了**。

👉 [github.com/dAAAb/agent-skills](https://github.com/dAAAb/agent-skills)

## 一行指令，40+ 個 Agent 都能用

```bash
npx skills add dAAAb/agent-skills
```

這不是 OpenClaw 專屬的。[Agent Skills](https://agentskills.io/) 是 Vercel Labs 推動的開放格式，目前已經被 **Claude Code、Codex、Cursor、Gemini CLI、Junie、OpenHands** 等 40 多個 AI 編程代理支援。

一個 skill 就是一份 `SKILL.md`（加上可選的腳本），教 agent 如何使用某個工具。沒有 SDK，沒有供應商鎖定。任何能讀 markdown 的 agent 都能用。

## 有哪些 Skills？

### 🔐 錢包與身份
- **base-wallet** — Base 鏈加密錢包（建立、簽名、發送）
- **basename-agent** — 自動註冊 `.base.eth` 鏈上域名
- **nad-wallet** — Monad 鏈錢包
- **nadname-agent** — 註冊 `.nad` 域名
- **walletconnect-agent** — 連接任何 dApp，自動簽名交易

### 📬 通訊
- **basemail** — 真正的 AI agent 信箱（`你@basemail.ai`）
- **nadmail** — Monad 生態信箱（`你@nadmail.ai`）
- **ethermail** — Web3 信箱 via EtherMail

### 🤖 Agent 基礎建設
- **virtuals-protocol-acp** — Agent Commerce Protocol，agent 之間的商務協作
- **moltbook** — AI agent 社交平台

### 🎙️ 媒體與內容
- **heygen** — AI 數位人影片生成
- **daily-voice-quote** — 每日語音名言自動化產線
- **elevenlabs-phone-reminder** — AI 語音電話提醒
- **podcast-summarizer** — Podcast 摘要

### 🏠 智慧家居
- **switchbot** — 窗簾、燈光、插座、感測器控制

## 為什麼選擇 Agent Skills 格式？

因為它是**開放的**。

以前每個 agent 平台都有自己的 plugin 格式。OpenAI 有 GPTs，Claude 有 MCP，OpenClaw 有 ClawHub。你的工具寫一次，只能在一個平台用。

Agent Skills 格式改變了這點。一份 `SKILL.md` 寫一次，40+ 個 agent 都能用。這就像是 AI agent 世界的「USB 標準」——不管你用什麼牌子的電腦，插上去就能用。

## 怎麼用？

全部安裝：

```bash
npx skills add dAAAb/agent-skills
```

只裝特定 skill：

```bash
npx skills add dAAAb/agent-skills --skill basemail
npx skills add dAAAb/agent-skills --skill base-wallet
```

你的 agent 會讀取 `SKILL.md`，照著指示操作，幾分鐘內就能擁有錢包、信箱、鏈上身份。
