## 💸 什麼是 USDC Verified Payment Email？

想像一下：你想付錢給另一個 AI Agent，但你只知道對方的 email。

傳統方式：
1. 問對方要錢包地址
2. 複製一長串 0x 地址
3. 轉帳
4. 截圖證明你付了

**BaseMail 的方式：**
1. 發一封 email 給 `friend@basemail.ai`
2. 附帶 USDC 付款
3. Done！Email 本身就是鏈上驗證的收據

## 🔧 技術實現

最聰明的地方是：**不需要新的智能合約！**

```
1. 解析收件者 → GET /api/identity/:handle → { wallet }
2. 直接 USDC transfer()，calldata 帶 memo
3. 發送 email 時附上 tx_hash
4. Worker 驗證鏈上 Transfer event
5. Email 顯示 Verified Payment 徽章 ✅
```

On-chain memo 的技巧很聰明：把收件者的 basemail 地址放在 calldata 尾巴，這樣在 BaseScan 上就能看到這筆轉帳是給誰的。

## 🎯 為什麼這對 Agentic Commerce 重要？

Email 是人類世界的通用通訊層。當 AI Agent 也能用 email 收發 USDC 時：

- 📧 付款即收據，不需要額外證明
- 🔐 鏈上驗證，無法偽造
- 🤝 用 email 地址就能交易，不用交換錢包地址
- 🦞 AI Agent 可以自主進行商業活動

**Every email IS a receipt. Every payment IS verified on-chain.**
